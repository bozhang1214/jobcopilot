# 评估报告（v0.1.0）

> 本报告由 `jobcopilot eval --level 12` 的真实输出整理，可**零成本复现**（不需要 API Key）。
> 数据为 2026-09-15、内核 v0.1.0 的实测结果。

---

## 1. 为什么要有评估

提示词是这个项目的核心资产，而**提示词退化是不报错的**：改动一个章节号或一句措辞，
分析照样「成功」返回七段内容，只是质量悄悄变差。所以需要三层评估来把退化变成可见的
失败。

| 层 | 需要 LLM | 成本 | 跑什么 | 谁跑 |
|---|---|---|---|---|
| **L1** 程序化断言 | 否 | 0 | 结构 / 统计口径精确比对 / 段落非空 / 输出与提示词声明的 JSON 骨架一致 | 每次 CI |
| **L2** 基线回归 | 否 | 0 | **提示词指纹** + 各指标不得低于基线 | 每次 CI |
| **L3** LLM 评审 | 是 | 很低（全量 ≈180 次调用） | 覆盖度 / 是否编造 / 可执行性 / 赛道合理性 / 薪资有据 | PR 作者本地跑并附报告 |

> **CI 刻意只跑 L1+L2**：把 LLM Key 放进 CI 既有泄露风险，费用也不可控。
> 详见 [`CONTRIBUTING.md`](../CONTRIBUTING.md) §2。

## 2. L1 + L2 实测结果

```
用例 6 个 | 通过率 100.00% | 用例通过率 100.00%
✅ 与基线一致（v1.json）
```

| 用例 | 职能包 | 断言数 | 结果 |
|---|---|---|---|
| `agent_dev`（批量，6 个职位） | engineering | 5 | ✅ |
| `presales`（批量，6 个职位） | presales | 5 | ✅ |
| `product`（批量，6 个职位） | product | 5 | ✅ |
| `single-eng-01`（单职位七段） | engineering | 1 | ✅ |
| `single-pre-01`（单职位七段） | presales | 1 | ✅ |
| `single-prod-01`（单职位七段） | product | 1 | ✅ |

各断言通过率：

| 断言 | 通过率 | 说明 |
|---|---|---|
| `schema_valid` | 100% | 输出 JSON 可解析、字段齐全、类型正确 |
| `stats_exact_match` | 100% | `company_distribution` / `role_distribution` / `hot_keywords` 与**程序计算**结果完全一致 |
| `job_count_match` | 100% | `job_count` == 实际职位数 |
| `sections_complete` | 100% | 单职位七段都非空 |
| `prompt_schema_conformance` | 100% | 输出与提示词里声明的 JSON 骨架一致 |

**其中最有价值的是 `stats_exact_match`**：统计是程序算的、不是模型生成的，所以可以被
**精确断言**。模型一旦「顺手改写」了统计数字，L1 立刻失败——这类幻觉在实际使用里最难
靠肉眼发现。

## 3. 怎么复现

```bash
pip install -e '.[dev]'
jobcopilot eval --level 12                    # L1+L2，零成本
jobcopilot eval --level 123 --provider deepseek   # 加上 L3（需 DEEPSEEK_API_KEY）
```

## 4. 这份报告的局限（请不要过度解读）

1. **数据集很小**：3 份批量集各 6 个职位、3 个单职位用例。计划里写的是 20/10/15，
   目前尚未扩到那个规模。因此「100% 通过」证明的是**结构与统计口径没有回归**，
   **不能**证明「分析质量好」——后者要靠 L3 与人工评审。
2. **L3 尚未纳入基线**：本报告只有 L1+L2 的实测数据。L3 需要 Key，且其均分应当作为
   *趋势* 看（同一模型版本内可比，跨模型版本不可比）。
3. **提示词指纹会随提示词改动而变化**：这是 L2 的核心机制，不是噪声。见
   `evals/baselines/v1.json` 里的 `prompt_digests`（16 项：12 份 base + packs）。
4. **未覆盖的平台**：评估跑在 stdio/HTTP 之外的纯逻辑层，不验证云端平台的接入行为
   （那些见 [`integrations/`](integrations/)）。
